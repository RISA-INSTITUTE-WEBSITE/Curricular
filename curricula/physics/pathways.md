## Level 2 package key

- PHY201 F1 = bending of beams and torsion; F2 = Poiseuille's law and Stokes' law. Select one.
- PHY202 H1 = electromagnetic energy conversion; H2 = mathematical analysis of eddy currents. Select one.
- PHY203 C1 = magnifier, C2 = microscope, C3 = telescope, C4 = cameras and imaging. Select two. G1 = laser types, beam characteristics, applications; H1 = single-/multimode, step-/graded-index, communications; I1 = phototransistors, photovoltaic detectors, applications. Select one group.
