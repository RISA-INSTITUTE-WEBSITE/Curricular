## Course family

Applied Physics is the common course family, with named career pathways following **Applied Physics in [Field of Application]**. Students complete a common scientific foundation and select career-oriented practicals and elective packages. The school → course/pathway → independent reusable module → topic hierarchy is retained; sections are internal groupings. Do not duplicate shared modules across pathways or schools. Existing `curricula/physics/` paths and PHY/MAT/PCS module codes remain stable for compatibility.

See [career pathways](pathways.md), [feasibility and implementation](feasibility.md) and [change record](CHANGELOG.md).

## Progression and elective rules

- Level 1: six compulsory modules; career-oriented practical choice in PCS102; no compulsory theory omissions.
- Level 2: seven compulsory modules; PHY201 select one two-topic package, PHY202 select one application, PHY203 select two instruments plus one three-topic photonics package. All other theory is compulsory. Integrated computing replaces a separate PCS201 module.
- Level 3: seven compulsory modules and optional PHY304. Select one package in each of PHY301 (7 topics), PHY302 (4), PHY303 (3), MAT301 (3), PHY305 (3) and PHY306 (3); PHY307 requires a supervised career-specific investigation. If PHY304 is selected, complete its core and one two-topic package. Optional PHY304 must not be a prerequisite of a compulsory module. Elective packages may be substituted only after prerequisite and workload review.
- Every pathway shares the same core learning outcomes. Revision topics require diagnostic verification and remediation, not automatic exemption. Unselected electives remain in the institutional catalogue. Safety-related content is compulsory where relevant.
- Students may change pathways with bridging and approval; career titles are descriptive educational pathways, not claims of professional registration or accreditation. The qualification naming, credit model and optional-module credit equivalence require institutional validation.

## Common assessment framework (design)

| Component | Physics | Mathematics |
|---|---:|---:|
| Knowledge checkpoints | 15% | 15% |
| Analytical / mathematical problem-solving | 25% | 35% |
| Practical / computational laboratories and projects | 25% | 15% |
| Final Module Assessment | 35% | 35% |

For modules with electives, allocate 70% of the final assessment to core and 30% to selected elective content; this does not apply to fully core modules. PCS102 and PHY307 need project-appropriate assessment rubrics before delivery. Require raw data, working, source code where applicable, uncertainty, reproducibility and oral verification. Assessment equivalence must be based on outcomes and learning hours, not number of topic titles.

## Delivery and scope

Use Python, NumPy, SciPy, SymPy, Matplotlib, Jupyter, Git and appropriate simulation and lab equipment. Supervised practicals use safe low-voltage circuits and controlled optical/thermal equipment. Nuclear activities use open data, simulation or authorised facilities; no unauthorised source handling. Physical skills require actual supervised experimental evidence where appropriate. Standalone Complex Analysis is excluded; relevant supporting methods are embedded. Academic peer review, credit and hours validation, detailed lesson-level outcomes, safety controls and formal assessment moderation remain outstanding. No website deployment is included.
