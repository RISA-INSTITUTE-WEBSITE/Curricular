## Module learning outcomes, teaching sections and laboratories

1. [DVE101 — DevOps Systems and Collaborative Computing Foundations](modules/DVE101/learning-outcomes.md) — Linux foundations, systemd, networking, Bash, Linux automation, Git/GitHub and YAML (including DVE101-00 onboarding).
2. [DVE201 — Continuous Delivery and Container Systems Engineering](modules/DVE201/learning-outcomes.md) — CI/CD and GitHub Actions, Docker, Compose, Jenkins and secure release workflows.
3. [DVE301 — Cloud Infrastructure and Configuration Automation](modules/DVE301/learning-outcomes.md) — cloud concepts/security, Terraform, Ansible and IaC change/recovery.
4. [DVE401 — Container Orchestration and Reliability Engineering](modules/DVE401/learning-outcomes.md) — Kubernetes, workloads, networking/storage, observability and incident response.
5. [DVE501 — Integrated DevOps Engineering Capstone](modules/DVE501/learning-outcomes.md) — architecture, infrastructure, automated delivery, operations, reliability and technical defence.
