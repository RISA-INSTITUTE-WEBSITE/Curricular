# Computer Science Curriculum

**Status:** Draft / under development.

This directory contains curriculum planning material for Computer Science at **RISA Institution of Applied Sciences**.

## Documents

- [General Computer Science — Concept Overview](general-computer-science-concept-overview.md) — proposed eight-module teaching sequence with topics from the original nine foundational areas, and mathematics and practical projects as cross-cutting elements.

## Proposed module teaching order

| Order | Module | Title |
| --- | --- | --- |
| 1 | CS101 | Computer Architecture & Data Representation |
| 2 | CS102 | Programming Fundamentals |
| 3 | CS201 | Data Structures & Algorithms |
| 4 | CS202 | Networking |
| 5 | CS221 | Database |
| 6 | CS222 | Operating Systems |
| 7 | CS301 | Software Engineering |
| 8 | CS302 | Artificial Intelligence |

## Review status

The sequence is a **contributor-proposed teaching order**, not an approved programme structure or detailed module syllabus. Module-level credits, prerequisites, learning outcomes, practical requirements and assessments still require development and academic review.

For repository-wide contribution and approval practices, see the [main Curricular README](../../README.md).
