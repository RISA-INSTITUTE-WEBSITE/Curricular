# Computer Science Curriculum

**Status:** Draft / under development.

This directory contains curriculum planning material for Computer Science at **RISA Institution of Applied Sciences**.

## Documents

- [General Computer Science — Concept Overview](general-computer-science-concept-overview.md) — proposed eight-module teaching sequence with topics drawn from the original foundational subject areas; mathematics and practical projects are cross-cutting elements.

### Module learning outcomes (teaching order)

1. [CS101 — Computer Architecture & Data Representation](modules/CS101/learning-outcomes.md) — architecture, binary representation and integrated hardware investigations.
2. [CS102 — Programming Fundamentals (Python 3)](modules/CS102/learning-outcomes.md) — programming concepts, control flow, functions and practical Python problem solving.
3. [CS201 — Data Structures & Algorithms](modules/CS201/learning-outcomes.md) — data structures, complexity, searching, sorting, graph algorithms and dynamic programming.
4. [CS202 — Networking](modules/CS202/learning-outcomes.md) — TCP/IP, addressing, routing, DNS, HTTP/HTTPS, wireless networks and safe troubleshooting.
5. [CS221 — Database](modules/CS221/learning-outcomes.md) — relational design, SQL, normalization, transactions and indexing.
6. [CS222 — Operating Systems](modules/CS222/learning-outcomes.md) — processes, threads, scheduling, memory, file systems, I/O and system investigation.
7. [CS301 — Software Engineering](modules/CS301/learning-outcomes.md) — requirements, design, collaboration, testing, quality assurance and team project work.
8. [CS302 — Artificial Intelligence](modules/CS302/learning-outcomes.md) — search, knowledge representation, machine learning, neural networks and responsible AI.

## Review status

The sequence and all eight learning-outcomes documents are **draft proposals**, not an institutionally approved degree programme or detailed module syllabi. Module-level credits, formal prerequisites, weekly teaching schedules, assessment instruments and academic approvals still require development or confirmation.

Each proposed learning-outcomes document includes a module purpose, 10 measurable learning outcomes, teaching-section alignment, suggested practical activities, teaching boundaries and outstanding academic-review decisions.

For repository-wide contribution and approval practices, see the [main Curricular README](../../README.md).
