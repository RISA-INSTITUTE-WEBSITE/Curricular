## Electives

Level 1: PCS102 career project. Level 2: PHY201 one two-topic package; PHY202 one application; PHY203 two optical instruments and one three-topic package. Level 3: PHY301 seven topics; PHY302 four; PHY303 three; MAT301 three; PHY305 three; PHY306 three; PHY307 career-oriented research. Optional PHY304, if taken, completes its own internal core and selected package for its MCC; omission does not block LCC/CCC. Validate selected packages against the assigned curriculum version and approved substitutions. All compulsory section requirements and revision checks must be complete. Entirely unselected elective content is not required.

## Eligibility

| Gate | MCC | LCC (proposed numeric rules) | CCC |
|---|---|---|---|
| Required content, activities, assessments and practicals | All prescribed | All required in level | All required across levels |
| Assessment pass | >=55% required graded assessments (per-item summative interpretation proposed) | Each module passes | Each module passes |
| Final module result | >=55% (implementation interpretation) | >=55% each | >=55% each |
| Average | Module result >=55% | >=60% level | >=60% course |
| Research | Normal MCC rule for PHY307 unless approved project-specific rule is stricter | >=70% for Level 3 proposed | >=70% PHY307 confirmed |
| Integrity / moderation / safety | Clear | Clear | Clear |

The 70% CCC research gate is not automatically a 70% MCC pass threshold for PHY307; distinguish module pass from course award eligibility. LCC numerical thresholds are not yet confirmed. No LCC possession requirement for CCC. A course average may be >=60% even if one level average is below 60%, provided all CCC-specific gates pass.

## Assessment design weights (as documented in curriculum)

| Component | Physics | Mathematics |
|---|---:|---:|
| Knowledge checkpoints | 15% | 15% |
| Analytical problem-solving | 25% | 35% |
| Practical / computational labs and projects | 25% | 15% |
| Final module assessment | 35% | 35% |

For modules with topic electives, final assessment 70% core / 30% selected electives. All-core modules use core assessment only. PCS102 and PHY307 require approved project-appropriate rubrics/weights; do not assume ordinary physics weighting. Assessment plans must identify graded summative tasks versus formative and competency gates.

## Average

Proposed interim arithmetic mean of required modules (6, 7, 7 or 20 respectively), including PHY307 for level/course where required. Once approved credit weights exist, transition to a versioned credit-weighted calculation. Compare unrounded marks; optional PHY304 excluded from required average. Formal credits, credit equivalence and rubric verification remain open.
